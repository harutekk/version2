# felden – Website

Statische Seite, bereit für GitHub Pages.

## Vor dem Veröffentlichen
In `impressum.html` und `datenschutz.html` die gelb markierten Platzhalter in [eckigen Klammern] ausfüllen (Name, Anschrift, E-Mail, Fotograf*in).

## Datenschutz
- Schriften liegen lokal in `fonts/` – keine Verbindung zu Google Fonts.
- Das YouTube-Video wird erst nach Klick geladen (youtube-nocookie.com), das Vorschaubild liegt lokal.
- Keine Cookies, kein Tracking.
